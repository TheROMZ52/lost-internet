### یه ماشین زمان کوچیک برای روزهایی که اینترنت قدیم رو یادته؛ نوستالژی تضمینی، رازها به عهده‌ی خودت.

<img src="https://skillicons.dev/icons?i=html,css,js&theme=dark" />

</div>

---

یک تجربهٔ تعاملی شبیه تکه‌ای از اینترنت بین سال‌های ۲۰۰۵ تا ۲۰۱۵ که انگار تصادفی پیدایش کرده‌ای: دسکتاپ Windows XP، پوشه‌های مرموز، ویدئوهای گمشده، گفتگوی رمزگذاری‌شده، وب‌سایت‌های قدیمی و ساختگی داخل Internet Explorer و یک رمز مخفی که بخش تازه‌ای را باز می‌کند.

همه‌چیز به یک داستان پنهان کوچک از نوع **ARG** متصل است.

بدون مرحلهٔ Build، بدون وابستگی و بدون دانلود اضافه؛ فقط HTML، CSS و JavaScript خالص.

---

## 01 / اجرا

فایل `index.html` را در مرورگر باز کن یا پوشه را با یک میزبان استاتیک اجرا کن:

```bash
npx serve .
```

این پروژه روی Vercel، GitHub Pages یا Netlify نیز قابل میزبانی است.

---

## 02 / بخش‌های تجربه

- بوت، ورود و دسکتاپ با حال‌وهوای Windows XP
- پنجره‌های قابل جابه‌جایی، نوار وظیفه و منوی Start
- پوشه‌هایی مثل My Documents و Recycle Bin
- Notepad، Media Player، Messenger و Internet Explorer
- وب‌سایت‌های ساختگی با سبک Geocities، دفتر یادداشت مهمان، انجمن و صفحهٔ شخصی
- فایل `mystery.dat` با محتوای متفاوت در هر بار باز شدن
- فایل `Vault.exe` و رمزی برای باز کردن آرشیو مخفی و داستان کامل
- افکت‌های صوتی تولیدشده در مرورگر و ذخیرهٔ پیشرفت در `localStorage`

<details>
<summary><b>04 / SEO</b></summary>
<br/>

فایل `index.html` شامل عنوان، توضیحات، canonical، کارت‌های Open Graph و Twitter با تصویر `og-image.png` و دادهٔ ساخت‌یافتهٔ JSON-LD از نوع VideoGame است.

فایل‌های `robots.txt` و `sitemap.xml` نیز موجودند. اگر دامنهٔ اختصاصی اضافه کردی، نشانی سایت را در هر سه محل به‌روزرسانی کن.

</details>
